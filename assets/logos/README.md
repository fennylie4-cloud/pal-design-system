# Logos

- `pal-wordmark.png` — The PAL wordmark, white ink on transparent, 397×220. Extracted byte-for-byte from the PNG embedded in the website's `logo.svg`. Use on `chrome` (cod-950) or dark photography only. Website nav shows it at 72×55.
- `pal-logo-square.png` — The same white wordmark centred on a 640×640 transparent square, for avatars and social profiles. Same ink rule.

There is no vector master. The shipped `logo.svg` only wraps the raster, so it was not copied. Never redraw or recolour the mark.
