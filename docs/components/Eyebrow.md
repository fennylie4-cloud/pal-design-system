# Eyebrow

The small uppercase gold label that names a section before its heading arrives; the site's main orientation device.

**Consumer provides:** `children`, one to five words. `rule={false}` drops the 20px gold line.

Set it 12–16px above the H2 (`section-heading`). Colour is `accent`, which is 2.3:1 on `bg-app`: it is decorative framing, so the heading under it must carry the meaning. If an eyebrow must be read on its own, colour it `accent-text`.

Source: `index.html .section-label` (16/24, 500, 0.15em). DESIGN.md says 14/20 and font-rules.md says gray; shipped code wins.
