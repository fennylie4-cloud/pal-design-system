# Icon

Lucide outline icons, drawn at 24 units and coloured by `currentColor`.

**Consumer provides:** `name`, `size` (16 inline, 28 on cards), `strokeWidth` (1.33 on marketing cards and buttons, 1.5–2 in the driver app).

Marketing icons sit in `accent`. Driver icons sit in `accent` for service type and `text-muted` for meta. Never use emoji.

Source: inline Lucide SVGs on the website, `lucide-react` in the driver web app. The native app uses Feather, Lucide's ancestor: align it to Lucide.
